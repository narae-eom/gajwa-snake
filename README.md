# 가좌 스네이크

가좌중학교 학생용 기본 스네이크. 프런트엔드는 GitHub Pages, 기록은 교사용 Google Sheets에 연결된 Apps Script 웹 앱을 사용합니다. Firebase나 독립 서버는 사용하지 않습니다.

## 페이지 구성 (1.2.0)

| 페이지 | 주소 | 용도 |
| --- | --- | --- |
| 입장 | `./` (index.html) | 학번 5자리와 이름만 입력. 학번에서 학년·반·번호를 자동 계산 (예: 10203 = 1학년 2반 3번) |
| 게임 | `play.html` | 게임 전용 화면. 학생 정보가 없으면 입장 화면으로 이동 |
| 랭킹 보드 | `board.html` | 교실 화면/프로젝터용 실시간 보드. `?grade=1&cls=2` 반 랭킹, `?view=all` 전교 랭킹, 주소 없이 열면 반 선택 화면 |

- 랭킹 보드: 반(전교) TOP 10(동순위), 참여 인원, 반 대항전(반별 개인 최고점 평균), 방금 기록 5건, 3초마다 자동 갱신, 전체화면.
- 학년별 반 수는 `config.js`의 `classesPerGrade`에서 바꿉니다. 기록이 있는 반은 자동으로 추가됩니다.
- 서버(Apps Script)도 학번에서 학년·반을 직접 계산하며, 5자리 학번이 아니면 저장하지 않습니다.

## 조작 반응 개선 (1.1.0)

- 키 입력 버퍼(최대 3개): 한 칸 이동 중 빠르게 누른 연속 방향키(예: ↑ 다음 ←)가 버려지지 않고 순서대로 적용됩니다.
- 한글 입력 상태에서도 W/A/S/D 동작: 문자 대신 물리 키 코드(`KeyboardEvent.code`)로 판별합니다.
- 화면 어디에 포커스가 있어도 방향키 수신(window 캡처 단계). 버튼 클릭 후에도 입력이 끊기지 않습니다.
- 조기 회전 보정: 칸 경계를 막 지난 직후(이동의 25% 이내) 누른 회전은 그 칸에서 바로 꺾이도록 처리합니다(직진 칸에 한해 1회).
- 이동 속도 140ms → 100ms/칸, 눈동자가 다음 입력 방향을 바로 바라봐 입력이 즉시 보입니다.

## 기능
- 10×9 작은 게임판, 고정 100ms 논리 틱과 requestAnimationFrame 렌더링 분리
- 머리부터 꼬리까지 동일한 경로를 따라가는 연속 이동, 둥근 몸통, 눈·쿠키·간단한 효과음
- 방향키 / WASD, 전체 화면, 충돌·완주만 저장
- Esc, 중도 종료 버튼, 탭 이탈은 저장하지 않음
- 학번·이름·학년·반 입력. 실명·학번을 그대로 표시. **학생 본인 인증은 없음**
- 학교 전체 / 학년·반별 개인 최고점 랭킹, 약 5초마다 조회
- 동점은 경쟁 동순위: 1,1,3. 1~10위만 표시하며 10위 동점자는 모두 포함(인원은 10명을 넘을 수 있음)
- 기록은 자동 만료하지 않고 관리자가 삭제할 때까지 보존

## 배포
GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).
`config.js`의 `appsScriptUrl`에 배포한 Apps Script의 `/exec` 주소를 넣습니다. 클라이언트에 비밀 인증키를 넣지 않습니다.
시트 프로젝트 설치는 `APPS_SCRIPT_SETUP.md`를 참고하세요.

## 로컬 실행 / 테스트
Node.js 설치 후:
```sh
node tests.mjs
node dev-server.cjs
```
서버가 출력하는 로컬 주소를 엽니다. 외부 폰트·빌드 도구·프레임워크 없이 작동합니다.

## 연결 방식과 제한
Apps Script 웹 앱은 '소유자로 실행 / 모든 사용자(Anyone)'로 배포합니다. 읽기는 검증된 JSONP 콜백, 쓰기는 숨겨진 HTML 폼/iframe POST 후 runId 상태 조회로 저장 성공을 확인합니다. CORS를 우회한 `fetch(...,mode:'no-cors')` 결과를 성공으로 간주하지 않습니다. 중복 POST는 같은 runId로 처리합니다.

Apps Script는 **Google에서 실행되는 서버 측 코드**입니다. 별도 서버가 없다는 뜻이지 서버 실행 자체가 없다는 뜻은 아닙니다. 약 5초 조회는 근실시간이지 실시간 푸시가 아니며 네트워크·Google 할당량·캐시에 따라 지연됩니다.

별도 인증을 하지 않으므로 타인 학번/이름 사칭·직접 API 제출·클라이언트 변조를 완전히 막지 못합니다. 수업용 가벼운 랭킹에 적합하며 고위험/상금 대회용은 아닙니다. 링크를 아는 사람은 전체 학번·실명이 포함된 상위 랭킹을 볼 수 있습니다. 학교는 실제 학생 정보 수집·공개·보존 범위를 확인해야 합니다.

교사용 시트 자체는 비공개 유지. 공개 저장소에 학생 명부·기록·교사 인증키를 커밋하지 않습니다. 자동 삭제 기능은 없으며 교사가 시트 행을 삭제하면 다음 조회에 반영됩니다(최대 캐시+조회 지연).

## 삭제
교사는 Google Sheets의 '게임기록'에서 대상 학번의 모든 행을 삭제합니다. TOP10 탭은 표시용 사본이며 다음 기록 저장/관리 함수 재계산 때 갱신됩니다. 학생용 화면에 관리자 삭제 기능이나 삭제 비밀번호를 공개하지 않습니다.

## 쿠키 모드 (1.2.1)

- 10열 × 9행, 초기 길이 4칸, 쿠키 10개 동시 배치. 쿠키 1개 = 1점.
- 먹은 쿠키만 제거하고 남은 쿠키 위치는 유지합니다. 뱀·다른 쿠키와 겹치지 않는 빈 칸에 새 쿠키를 배치합니다.
- 빈 칸이 10개 미만이면 가능한 수만큼 표시하며, 90칸을 모두 채우면 86점으로 완주합니다.
- Enter·Space·시작하기로 준비 화면을 닫고 방향키를 눌러 출발합니다. 기존 한글 이름 입력·랭킹·저장 방식을 유지합니다.
- 가좌중학교 공식 [학교상징](https://kajwa.icems.kr/sub/info.do?m=0104&s=kajwa)을 참고한 게임용 심볼(`gajwa-cookie-logo.webp`)을 입장 화면·헤더·은은한 배경에 적용했습니다. 학교의 공식 교표를 대체하는 심볼은 아닙니다.
- 기존 Google Sheets 기록은 초기화하거나 삭제하지 않습니다.

- 지렁이 얼굴은 큰 위·아래 눈과 둥근 머리로 재구성하고, 이동 속도를 130ms/칸에서 100ms/칸(1.3배)으로 높였습니다.

## 게임 시작 횟수 (1.2.3)

- 같은 브라우저의 같은 학번·이름에 대해 최근 10분 시작한 게임을 최대 3판으로 제한합니다. 방향키로 실제 출발할 때 차감하며, 중도 종료·충돌·완주 모두 한 판으로 셉니다. 준비 화면을 닫는 것만으로는 차감하지 않습니다.
- 상단에 남은 쿠키 3개를 표시하고, 3판을 시작하면 결과 화면에서 다시 시작을 비활성화합니다. 새로고침·학생 변경 후에도 남은 횟수가 유지되고, 10분이 지나면 오래된 시도부터 다시 열립니다.
- 브라우저의 localStorage에 임의 salt로 해시한 학번·이름별 시도 시각만 기록합니다. **이 제한은 현재 브라우저의 이용 안내 기능**으로, 다른 기기·브라우저나 저장소 삭제를 막는 서버 측 보안 제한은 아닙니다. 전교 기기 공통 강제 제한이 필요하면 Apps Script에 서버 측 시작 기록·원자적 할당을 추가해야 합니다.

## 표정 애니메이션 (1.2.4)
- 쿠키에 닿는 순간 입을 크게 벌리고, 먹은 뒤 잠깐 씹는 표정을 표시합니다.
- 평소 이동 중에는 붉은 갈라진 혀를 주기적으로 낼름거리며, 먹는 중·정지·충돌 시에는 혀를 숨깁니다. 움직임 줄이기를 선택한 환경에서는 혀 움직임을 끕니다.

## 전체 화면 반응형 개선 (1.2.5)
- 게임판·점수/최고점/남은 쿠키·게임 버튼·모달을 화면 너비와 높이에 맞춰 조절하고, 좁은 곳에서는 버튼을 줄바꿈합니다. 최고점 라벨이 세로로 깨지지 않습니다.
- 입장 폼은 낮은 화면에서 위쪽이 잘리지 않고 스크롤되며, 자동 포커스 때문에 화면이 움직이지 않도록 했습니다.
- 랭킹·반 선택 화면은 작은 화면에서 세로형으로 재배치하고, 낮은 가로 화면에서는 내부 내용을 억지로 축소하지 않고 페이지가 스크롤되게 합니다. 홈 버튼은 랭킹 오른쪽 상단에 유지합니다.
